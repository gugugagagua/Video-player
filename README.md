# 视频集播放器（Android）
[**English**](./README-en.md) | [**简体中文**](./README.md)
#该软件由AI辅助完成

## 技术栈

- Kotlin + Jetpack Compose（Material 3）
- Media3 ExoPlayer（视频播放）
- Room（数据持久化）
- Coil（封面图片加载）
- SAF（Storage Access Framework，文件夹导入）

## 功能对照

| 桌面版功能 | Android 版实现 |
|-----------|--------------|
| 导入文件夹生成视频集 | SAF 选择目录 → `DocumentFile` 扫描视频 |
| 视频集封面（cover.png / 首帧） | `MediaMetadataRetriever` 提取首帧或读取 cover.png |
| 分组管理（新建/重命名/删除/移动） | Room + 首页分组筛选与长按菜单 |
| 播放列表、上一集/下一集 | 播放页底部弹层 + 控制栏 |
| 播放进度记忆（续播） | `videos.last_position` + 卡片"继续观看"角标 |
| 音量、全屏 | ExoPlayer 音量 + 系统栏隐藏 |
| 深/浅色主题 | Material3 跟随系统 |

## 构建

1. 使用 Android Studio（Koala 或更新）打开本目录
2. 等待 Gradle 同步（依赖会自动下载）
3. 连接设备或启动模拟器（Android 8.0+，API 26+）
4. 点击 Run ▶

也可以在命令行构建：

```
gradlew assembleDebug
```

产物位于 `app/build/outputs/apk/debug/`。

## 使用说明

### 媒体库目录（推荐，体验同电脑版）

首次启动会引导你设置一个**媒体库根目录**，之后按以下层级放置视频即可：

```
媒体库根目录/
├── 电视剧A/          ← 自动成为一个视频集
│   ├── cover.png     ← 可选，作为封面
│   ├── 第01集.mp4
│   └── 第02集.mp4
├── 纪录片B/          ← 另一个视频集
│   └── ...
└── 随手拍.mp4        ← 根目录散放的视频归入「未整理」
```

设置后**每次启动自动扫描**，也可点右上角刷新按钮手动扫描；新增/删除/改名文件都会同步。

两种模式：

- **授权目录模式（推荐）**：用系统文件选择器授权一次，无需任何权限，可上架 Play。
- **固定路径模式**：直接使用 `Movies/视频集播放器` 目录，用文件管理器/USB 拷视频进去即可，最接近电脑版。需要「所有文件访问」权限（跳转到系统设置页开启），Google Play 会限制此类权限，自用或侧载无影响。

右上角「文件夹图标」可随时更换目录、切换模式、重新扫描。

### 导入视频

点击右上角「下载」图标，有两种导入方式：

1. **导入视频文件 / 压缩包**：可一次多选
   - 视频文件：直接导入为视频集（名称取自文件名）
   - 压缩包（zip / rar）：自动解压，仅提取其中的视频
   - 选择后弹出命名确认框，已自动填入提取的文件名，可逐个修改后确认
2. **导入文件夹**：将已有目录整体作为一个视频集

无论哪种方式，视频都会按 **媒体库根目录 / 视频集名称 / 视频文件** 的层级自动归类存放，导入完成后自动扫描入库。

### 其他操作

1. 也可以不设媒体库目录，点右下角「导入文件夹」单独导入某个目录
2. 支持常见格式：mp4 / mkv / avi / mov / wmv / flv / webm / ts 等
3. 目录下如有 `cover.png`（或 poster/folder/thumbnail）会作为封面，否则自动截取首个视频第一帧
4. 点卡片进入播放；长按卡片可重命名 / 移动分组 / 删除
5. 播放页点击屏幕中央可隐藏/显示控制栏；播放完成后自动播放下一集

## 数据存储

- 媒体库：应用私有数据库（Room）
- 封面：应用私有目录 `files/covers/`
- 视频文件本身不做拷贝，通过 SAF 授权读取原始位置
