# 视频集播放器（Android）
#该软件由AI辅助完成

**当前版本：1.1.0**（versionCode 2）

## 技术栈

- Kotlin + Jetpack Compose（Material 3）
- Media3 ExoPlayer（视频播放）
- Room（数据持久化）
- Coil（封面图片加载）
- SAF（Storage Access Framework，目录授权与导入）
- junrar（RAR 解压；ZIP 使用 Java 内置 `java.util.zip`）

## 功能对照

| 桌面版功能 | Android 版实现 |
|-----------|--------------|
| 导入文件夹生成视频集 | SAF 选择目录 → `DocumentFile` 扫描视频 |
| 视频集封面（cover.png / 首帧） | `MediaMetadataRetriever` 提取首帧或读取 cover.png |
| 分组管理（新建 / 重命名 / 删除 / 移动） | 分组以文件夹卡片呈现，点击**逐层进入**，长按可重命名 / 删除 |
| 分组封面 | 从组内任一视频集的封面中选择 |
| 播放列表、上一集 / 下一集 | 播放页底部弹层 + 控制栏 |
| 播放进度记忆（续播） | `videos.last_position`，退出/切集/定时自动保存 |
| 观看进度可视化 | 视频集封面角标「看到 N/M 集」+ 进度条；播放列表每集显示已看 / 未看与进度条 |
| 搜索 | 顶栏搜索，匹配视频集名称与视频文件名 |
| 播放控制 | 播放/暂停、进度拖拽、上下集、倍速、全屏 |
| 快进 | 长按加速 2 倍速（竖屏下方区域 / 横屏右侧区域） |
| 全屏 | 强制横屏（不受系统「自动旋转」开关影响）|
| 深 / 浅色主题 | Material3 跟随系统 |
| 音量 | 交由手机物理音量键控制 |

## 构建

1. 使用 Android Studio（Koala 或更新）打开本目录
2. 等待 Gradle 同步（依赖会自动下载）
3. 连接设备或启动模拟器（Android 8.0+，API 26+）
4. 点击 Run ▶

命令行构建：

```
gradlew assembleDebug     :: 调试版
gradlew assembleRelease   :: 签名正式版
```

产物位于 `app/build/outputs/apk/`。

> 命令行构建需先设置 `JAVA_HOME` 指向 JDK 17 或更高（Android Studio 自带的 `jbr` 即可）。
> Release 签名读取项目根目录的 `keystore.properties`（该文件与 `*.jks` 已加入 `.gitignore`，请勿提交）。

## 使用说明

### 媒体库目录（推荐）

首次启动会询问**是否自动创建视频存放文件夹**，也可以自行选择已有目录，之后按以下层级放置视频：

```
媒体库根目录/
├── 电视剧A/          ← 自动成为一个视频集
│   ├── cover.png     ← 可选，作为封面
│   ├── 第01集.mp4
│   └── 第02集.mp4
├── 纪录片B/          ← 另一个视频集
│   └── ...
└── 随手拍.mp4        ← 根目录散放的视频归入「未整理」
```

设置后**每次启动自动扫描**，也可点右上角刷新按钮手动扫描；新增 / 删除 / 改名文件都会同步。

两种模式：

- **授权目录模式（推荐）**：用系统文件选择器授权一次，无需任何权限，可上架 Play。
- **固定路径模式**：直接使用 `Movies/视频集播放器` 目录，用文件管理器 / USB 拷视频进去即可，最接近电脑版。需要「所有文件访问」权限（跳转到系统设置页开启），Google Play 会限制此类权限，自用或侧载无影响。

右上角「文件夹图标」可随时更换目录、切换模式、重新扫描。

### 导入视频

点击右上角「下载」图标，有两种导入方式：

1. **导入视频文件 / 压缩包**：可一次多选
   - 视频文件：直接导入为视频集（名称取自文件名）
   - 压缩包（zip / rar）：自动解压，仅提取其中的视频
   - 选择后弹出确认框，名称已按文件名自动填入，可逐个修改
2. **导入文件夹**：将已有目录整体作为一个视频集

**智能归并**：导入多个文件时自动识别公共部分并建议合并，例如

```
咕咕嘎嘎 1-7集.zip  ┐
咕咕嘎嘎8-10集.zip  ┘ → 建议合并为「咕咕嘎嘎」
```

- 自动剥离「1-7集」「第01集」等集数后缀后再比对
- 识别「第一季 / 第二部 / Season 2 / 剧场版 / 番外 / OVA / 上部」等**明确分开标识**，这类不会自动合并
- 归并结果在确认框中标注来源文件，可改名，也可点右侧按钮**拆分**为独立导入

无论哪种方式，视频都会按 **媒体库根目录 / 视频集名称 / 视频文件** 的层级自动归类存放，导入完成后自动扫描入库。

### 分组与视频集

- 首页根层：分组显示为**文件夹卡片**，与未分组的视频集混排
- 点击文件夹**进入该分组**，顶部显示「← 返回全部 / 分组名」面包屑
- **长按分组**：打开 / 设置封面 / 重命名 / 删除
- **长按视频集**：播放 / 重命名 / 移动到分组 / 删除
- 设置分组封面时，可从该分组内**任一视频集的封面**中选择，也可清除

### 搜索

点击顶栏 🔍 进入搜索模式：

- **视频集**：按名称实时过滤（含分组内的视频集）
- **视频**：按文件名模糊匹配（如输入「第05集」）
- 点击视频结果**直接跳转到该集播放**

### 观看进度

- 视频集卡片右下角显示「看到 N/M 集」，封面底部有整体推进进度条；全部看完显示「✓ 已看完」
- 播放列表中每集显示状态图标与单集进度条：正在播放 / 已看完 / 看到 mm:ss / 未看
- 打开播放列表时会自动补全缺失的时长，使进度百分比准确
- 退出播放页、切换集、播放过程中（每 5 秒）都会保存进度，下次自动续播（忽略小于 3 秒的零碎进度）

### 播放操作

| 操作 | 说明 |
|---|---|
| 点击屏幕中央 | 显示 / 隐藏控制栏 |
| 长按（竖屏下方 1/4 / 横屏右侧 1/4） | 2 倍速播放，松手恢复；屏幕上方显示 `»2倍速` 提示 |
| 拖动进度条 | 跳转播放位置 |
| ⏮ / ⏯ / ⏭ | 上一集 / 播放暂停 / 下一集 |
| 列表按钮 | 打开播放列表（含每集进度） |
| 全屏按钮 | 进入全屏并**强制横屏**（竖屏视频则竖屏全屏），不受系统自动旋转影响 |
| 返回键（全屏时） | 退出全屏而非直接返回 |

播放结束后自动播放下一集；遇到无法播放的视频会给出明确提示并可跳到下一集。

## 数据存储

- 媒体库：应用私有数据库（Room，`video_player.db`）
- 封面：应用私有目录 `files/covers/`（JPEG）
- 视频文件本身不做拷贝（导入的文件会复制到媒体库目录），通过 SAF 授权或文件路径读取

## 权限说明

| 权限 | 用途 | 备注 |
|---|---|---|
| 无（SAF 授权目录模式） | 读取用户选定的目录 | 推荐，无需任何权限 |
| `MANAGE_EXTERNAL_STORAGE` | 「固定路径模式」直接读写 `/sdcard` 目录 | 可选；Google Play 对普通应用审核较严，自用 / 侧载无影响 |

## 已知限制

- 压缩包仅支持 **zip / rar**（7z 暂不支持）
- 目录扫描为**单层**：媒体库根目录下的子目录即视频集，不再递归更深层级
- 若导入时文件夹创建失败（未授权），会自动回退到应用私有目录
